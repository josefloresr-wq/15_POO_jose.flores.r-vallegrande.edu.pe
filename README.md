# Agenda de Contactos

Proyecto desarrollado en Java para gestionar una agenda de contactos utilizando una estructura basada en MVC.

## Funcionalidades

- Registrar contactos.
- Listar contactos registrados.
- Buscar contactos por nombre o apellido.
- Realizar búsquedas parciales o exactas.
- Eliminar contactos mediante su ID.
- Menú interactivo con opciones del 1 al 5.

## Estructura del proyecto

- **model:** Contiene la clase `Contacto`.
- **controller:** Contiene la lógica para registrar, listar, buscar y eliminar contactos.
- **view:** Contiene la presentación del título, mensajes y menú.
- **app:** Contiene la clase principal `Main`.

## Contactos iniciales

El sistema cuenta con 5 contactos predeterminados para realizar las pruebas de listado, búsqueda y eliminación.

## Tecnologías utilizadas

- Java
- ArrayList
- Scanner
- Programación Orientada a Objetos
- Patrón MVC
